# Verto

**Verto** (from Latin *verto* — "I turn / transform") is a **desktop file converter that works completely offline**. No cloud, no accounts, no telemetry.

Verto's conversion engine, **Morphix**, handles all format detection and conversion work under the hood. The interface is themed as **FileForge** — a blacksmith's forge (anvil, hammer, output slot).

| Platform | Support |
|----------|---------|
| **Linux** | **Primary** |
| **macOS** | Secondary |
| **Windows** | Optional |

See the full repository for install instructions after the complete source is uploaded.
